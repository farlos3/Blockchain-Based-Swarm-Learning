Organizations

One per swarm node. The leader shown is for the next round number.

Training

Runs on the Python trainer; every round is written to this ledger.

Clear rounds deletes the recorded rounds from state so the next run starts at round 1. Block height does not drop — committed blocks cannot be deleted, and the clear is itself a transaction, so the history still shows what was there and who cleared it.

Rebuild network destroys the ledger volumes and recreates every channel, which is the only way height goes back to its starting point. Takes about three minutes and restarts the gateway, so this page loses its connection until it is done.

Model weights are rebuilt at the start of every run, so there is nothing else to clear.

Rule checks

Fires transactions the chaincode must refuse. All four are rejected, so nothing is written to the ledger.

Validation accuracy per round

Read back from the ledger, one line per model. This is the validation split; the test split is scored once at the end of a run and shown in the training summary.

One row per finished model: what it reached, and what that took. Accuracy on the left is validation (scored every round) and test (scored once at the end). The cost columns are measured from the counters before and after the run, divided by the rounds it completed.
