1 · เทรน FL กับ SL แยกกัน แล้วเทียบ global model ทุกรอบ

ใน grid ทั้งสองฝั่งได้ update ชุดเดียวกัน ตรงนี้แยกให้ขาด: FL เทรนเองตั้งแต่ต้นกับ server กลาง แล้ว SL เทรนใหม่ทั้งหมดอีกครั้ง โดยมี leader ที่ chaincode เลือกเป็นคนรวม ถ้าการแทนที่ถูกต้อง hash ของ global model ต้องเท่ากันทุกรอบ · รอบของ SL เขียนลง ledger จริงเหมือน run ปกติ · LSTM เทรนบน CPU, Transformer บน GPU · ผลจากหน้านี้แสดงอย่างเดียว ไม่บันทึกลง verify.json

ผลที่บันทึกไว้จาก python verify.py

    3 · ลองทำผิดกฎบนทุก channel

    ใน FL server กลางทำสิ่งเหล่านี้ได้โดยไม่มีใครรู้ บน swarm ทุกครั้งต้องถูก chaincode ปฏิเสธ และ ledger ต้องเหมือนเดิมหลังลอง: ไม่มีรอบใหม่ ไม่มี update ค้าง และ hash ของรอบที่ปิดแล้วไม่เปลี่ยน
